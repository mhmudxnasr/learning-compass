Learning materials, rebuilt

One lesson. One clear place to start.

What changed

Less guessing before you learn.

If a lesson says where to start, Compass follows it. If not, it tries HTML, then the original source. PDF and NotebookLM stay one tap away when available.

Original

Keep the source close

The original video, article, audio, or book stays available. A companion helps you learn; it does not hide the source.

HTML

Read one clean canonical document

The Arabic HTML preserves the source's complete argument in a simple, source-specific reading design. After the first successful online open, it can reopen offline.

PDF

Read or annotate on the tablet

The A4 PDF is printed from the exact canonical HTML instead of being rewritten as a second document. The PDF still needs a connection to open.

NotebookLM

Use AI for retrieval

When a separate learning build is requested, it starts with one hard source-based quiz. Other formats are used only when they fit the material.

HTML + PDF

One source becomes one coherent pair.

The workflow stays linear from complete source extraction to one verified HTML/PDF pair. No image requests, preset themes, or extra interaction layer interrupt the reading.

Canonical HTMLOne reading body
  1. Extract the complete sourceEvery source word belongs to a verified coverage span.
  2. Author one Arabic documentIts structure, type, and color come from this source—not a template.
  3. Validate before publicationRTL, accessibility, responsive behavior, coverage, and print parity must pass.

Then publish HTML and PDF together.

A4 PDFExact print rendition

The same reading travels with you.

Use the tablet or paper. The PDF keeps the HTML's content and order, with print-aware page breaks and no separate authored body.

Atomic pair
Neither file becomes visible unless both exact files pass and publish together.

Focused AI

NotebookLM gets a job, not a format list.

It does not build everything. When you request a learning output, Compass chooses the smallest useful set and records what is truly ready.

The default

One hard, source-based quiz.

Retrieval comes first. Extra media is added only when the source has a real structure that the medium can explain better.

5–8 questions
  • Hints before explanations
  • At least one transfer question
  • No change to progress or mastery

What stayed the same

Better materials. The same learning system.

  • Threads, Levels, Lessons, Notes, and Recall stay where they are.
  • The original source remains available beside its companions.
  • The companion adds no quiz, scores, streaks, XP, or second progress system.
  • NotebookLM never changes progress or mastery by itself.
  • HTML is the complete Arabic source body; PDF is printed from it exactly.
  • Compass never joins HTML from one revision with PDF from another.
